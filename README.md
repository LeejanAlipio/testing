# Testing Practice Repository

This repository is focused on learning and practicing JavaScript testing concepts with Jest.

## What this repo includes

- Small utility functions for string manipulation and arithmetic
- Unit test files that demonstrate matcher usage and test organization
- A simple setup for running tests in normal and watch modes

## Getting started

1. Install dependencies:
   - `npm install`
2. Run all tests:
   - `npm test`
3. Run tests in watch mode:
   - `npm run watch`
